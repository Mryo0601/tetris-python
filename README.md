# テトリスゲーム

このプロジェクトは、Pythonで実装されたクラシックなテトリスゲームです。`pygame`ライブラリを使用しており、レベル選択やランキング機能など、さまざまな機能を備えています。

---

## 特徴

- 7種類のテトロミノ（I, O, T, S, Z, J, L）を使用したクラシックなテトリスゲーム
- レベル選択（1～10）で難易度を調整可能
- ランキング機能でハイスコアを記録
- スムーズな操作性（キー長押しや高速落下に対応）
- バックグラウンドミュージック（コロブチカのテーマ）
- 一時停止やゲーム再開機能

---

## フォルダ構成
```
tetris-project/
├── block.py         # テトロミノの形状と動作を定義
├── constants.py     # ゲームの定数（画面サイズ、色、スコア計算など）
├── main.py          # ゲームのエントリーポイント
├── tetris.py        # ゲームのロジック（グリッド管理、衝突判定、スコア計算）
├── bgm.mp3          # バックグラウンドミュージック
├── ranking.json     # スコア保存用ファイル
└── __pycache__/     # コンパイル済みPythonファイル（自動生成）
```

## 遊び方

### インストール手順

1. このリポジトリをクローンします：

   ```bash
   git clone https://github.com/your-username/your-repo.git
   cd your-repo

   依存パッケージをインストール：
   pip install pygame numpy

   ゲームを起動：
   python main.py

## 🕹️ 操作方法

- ← / →：ブロックを左右に移動  
- ↓：ブロックを下に移動  
- ↑：ブロックを回転  
- スペースキー：即時落下  
- `P`：一時停止  
- `R`：ゲーム再スタート（ゲームオーバー後）  
- `H`：ハイスコア表示

---

## 💻 必要な環境

- Python 3.10 以上
